Brain · Controller

Main Programmable Microcontroller

The programmable controller that acts as the brain of the robot, executing sensor logic and motor control loops.

What is it?

An open-source microcontroller board based on the Microchip ATmega328P. It can be programmed via the Arduino IDE using C/C++ to read inputs and control external hardware.

Why do we use it?

It acts as the robot's central brain. It reads distance data from the three ultrasonic sensors, decides which path is clear, and sends driving commands to the L298N motor driver module.

Motor Control · Dual H-Bridge

L298N Motor Driver Module

Dual H-Bridge High-Power Motor Driver

Controls the high-current power and rotational direction of the four M20 DC gear motors safely from Arduino signals.

Dual H-Bridge IN1–IN4 Control D9, D8 (Left Motors) D11, D12 (Right Motors) 7.4V Motor Supply

What is it?

A dual H-bridge motor driver module based on the ST L298N IC. It features a heavy-duty heatsink, screw terminal blocks for motor/power connections, and 5V logic inputs.

Why do we use it?

Arduino pins can only supply 5V at 20mA, which is not enough to power DC motors. The L298N module draws power from the 7.4V LiPo battery and safely delivers high current to the left and right motor pairs based on PWM and direction inputs from the Arduino.

How the Robot Works

The robot continuously reads its three ultrasonic sensors and uses that information to steer its 4WD drivetrain away from obstacles.

Ultrasonic Sensors
↓
Arduino UNO
↓
Decision Logic
↓
L298N Motor Driver
↓
4× M20 Motors (4WD)
↓
Robot Movement

Sensor Positions

LEFTTRIG D2 / ECHO D3
CENTERTRIG D4 / ECHO D5
RIGHTTRIG D6 / ECHO D7

The center sensor detects obstacles directly ahead. The left and right sensors detect obstacles on either side in the angled bumper.

Decision Rules (from the code)

  • Emergency Reverse & Turn (Center < 15 cm): Back up straight (220 ms at -200 PWM), then pivot left in place (220 ms at left -200, right +200 PWM).
  • Left Obstacle Evade (Left < 12 cm): Differential spin right in place (left +200, right -200 PWM).
  • Right Obstacle Evade (Right < 12 cm): Differential spin left in place (left -200, right +200 PWM).
  • Clear Path: Move forward smoothly at PWM 130 on all four wheels.

🧮 Autonomous Decision Matrix

Real-time obstacle evaluation matrix executed in the 50 ms loop in autoracerl298n.ino:

Sensor Condition Distance Threshold Robot Behavior Left Motors (OUT1/2) Right Motors (OUT3/4)
Path Ahead Clear Center ≥ 15 cm, Left & Right ≥ 12 cm Cruise forward smoothly FORWARD (130) FORWARD (130)
Obstacle on Left Left < 12 cm, Right ≥ 12 cm Differential pivot right FORWARD (200) REVERSE (-200)
Obstacle on Right Right < 12 cm, Left ≥ 12 cm Differential pivot left REVERSE (-200) FORWARD (200)
Front Obstacle / Corner Center < 15 cm 1. Reverse 220 ms
2. Pivot Left 220 ms		 1. REVERSE (-200)
2. REVERSE (-200)		 1. REVERSE (-200)
2. FORWARD (200)

Arduino Program

Upload this program to the Arduino UNO using the Arduino IDE. Built entirely with standard built-in Arduino functions — no external libraries required.

Autonomous_Racer_Robot.ino 

// Motor Driver Pins (PWM pins on Uno: 3,5,6,9,10,11)
const int IN1 = 9;   // Left motor speed
const int IN2 = 8;   // Left motor direction
const int IN3 = 11;  // Right motor speed
const int IN4 = 12;  // Right motor direction (D12)

// Ultrasonic Sensor Pins
const int trig1 = 2;  const int echo1 = 3;   // Left sensor
const int trig2 = 4;  const int echo2 = 5;   // Center sensor
const int trig3 = 6;  const int echo3 = 7;   // Right sensor



const float MAX_SENSOR_DISTANCE       = 200.0;  // cm
const float FRONT_OBSTACLE_THRESHOLD  = 15.0;   // cm - center sensor triggers backup + turn
const float SIDE_OBSTACLE_THRESHOLD   = 12.0;   // cm - left/right sensors trigger turn
const unsigned long SENSOR_INTERVAL   = 50;     // ms between sensor reads
const unsigned long BACKUP_DURATION   = 220;    // ms to reverse when front obstacle detected

unsigned long lastSensorReadTime = 0;

// ==========================================
// MOTOR CONTROL
// ==========================================

void motor1(int speed) {       //Left Motor speed
  if (speed > 0) {
    digitalWrite(IN1, LOW);
    analogWrite(IN2, speed);       // Forward
  } else if (speed < 0) {
    digitalWrite(IN1, HIGH);
    analogWrite(IN2, speed);      // Backward 
  } else {
    digitalWrite(IN1, HIGH);
    analogWrite(IN2, HIGH);           // Stop
  }
}

void motor2(int speed) {      //Right Motor speed 
  if (speed > 0) {
    digitalWrite(IN3, LOW);
    analogWrite(IN4, speed);       // Forward
  } else if (speed < 0) {
    digitalWrite(IN3, HIGH);
    analogWrite(IN4, speed);      // Backward (negate to get positive PWM value)
  } else {
    digitalWrite(IN3, HIGH);
    analogWrite(IN4, HIGH);           // Stop
  }
}

void motorControl(int leftSpeed, int rightSpeed) {
  motor1(leftSpeed);
  motor2(rightSpeed);
}



void setup() {
  Serial.begin(9600);

  // Ultrasonic pins
  pinMode(trig1, OUTPUT); pinMode(echo1, INPUT);
  pinMode(trig2, OUTPUT); pinMode(echo2, INPUT);
  pinMode(trig3, OUTPUT); pinMode(echo3, INPUT);

  // Motor pins
  pinMode(IN1, OUTPUT); pinMode(IN2, OUTPUT);
  pinMode(IN3, OUTPUT); pinMode(IN4, OUTPUT);

  motorControl(0, 0); // Start stopped
  Serial.println("Robot Ready!");
}


void loop() {
  unsigned long currentMillis = millis();


  if (currentMillis - lastSensorReadTime >= SENSOR_INTERVAL) {
    lastSensorReadTime = currentMillis;

    float leftDist   = getDistance(trig1, echo1);
    float centerDist = getDistance(trig2, echo2);
    float rightDist  = getDistance(trig3, echo3);

    Serial.print(leftDist);
    Serial.print("       ");
    Serial.print(centerDist);
    Serial.print("       ");
    Serial.println(rightDist);


    if (centerDist < FRONT_OBSTACLE_THRESHOLD) {
      // Back up briefly, then turn left for the same duration
      motorControl(-200, -200);
      delay(BACKUP_DURATION);
      motorControl(-200, 200);  // Turn Left in place
      delay(BACKUP_DURATION);
    }
    else if (leftDist < SIDE_OBSTACLE_THRESHOLD) {
      motorControl(200, -200);  // Turn Right in place
    }
    else if (rightDist < SIDE_OBSTACLE_THRESHOLD) {
      motorControl(-200, 200);  // Turn Left in place
    }
    else {
      motorControl(130, 130);   // Go Forward
    }
  }
}

float getDistance(int trigPin, int echoPin) {
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);
                                                                                                                                                                         
  long timeout = (MAX_SENSOR_DISTANCE * 2.0 / 0.0343) + 3000;
  long duration = pulseIn(echoPin, HIGH, timeout);

  if (duration == 0) return MAX_SENSOR_DISTANCE;

  float distance = duration * 0.0343 / 2.0;

  if (distance > MAX_SENSOR_DISTANCE) return MAX_SENSOR_DISTANCE;
  if (distance < 0) return 0.0;

  return distance;

}

Assembly & Setup

Follow these steps to build the 4WD Autonomous Racer Robot.

  1. Prepare the 4WD Chassis

    Lay out the 4WD chassis base and identify the mounting points for the four M20 motors, L298N driver, Arduino UNO, 7.4V LiPo battery, and front sensor bumper.

  2. Attach 4× M20 Motors & Wheels (with 3D Clamps & Bat Grip)

    Secure the four 300 RPM M20 micro gear motors into the chassis slots (2 on the left, 2 on the right) using the 3D-printed motor clamps (motor clamp.stl) fastened tightly with M2×10mm socket head cap bolts and locked with M2 stainless steel hex nuts. Cut four rings from the rubber cricket bat grip and stretch them securely over the 34mm small wheels for enhanced octopus-pattern traction, then press each wheel firmly onto the motor output shaft.

  3. Mount Arduino UNO and L298N Motor Driver

    Fasten the Arduino UNO and the L298N motor driver module securely onto the chassis platform using the three M3×10mm countersunk hex screws (m3_csk_screws.jpg) and standoffs, ensuring flush seating with the chassis baseplate.

  4. Mount the Three Ultrasonic Sensors

    Insert the three HC-SR04 ultrasonic sensors into the front angled bumper housing (Left, Center, Right), ensuring they face horizontally outward.

  5. Connect Sensor Wires

    Connect sensor VCC to Arduino 5V, GND to GND, Left TRIG/ECHO to D2/D3, Center TRIG/ECHO to D4/D5, and Right TRIG/ECHO to D6/D7 using DuPont jumper wires.

  6. Connect Motor Wires to L298N

    Wire the two left M20 motors in parallel to OUT1 & OUT2 terminals. Wire the two right M20 motors in parallel to OUT3 & OUT4. Connect L298N logic inputs IN1→D9, IN2→D8, IN3→D11, and IN4→D12 on the Arduino.

  7. Connect the 7.4V LiPo Power Supply

    Connect the 7.4V LiPo battery (+) to the L298N 12V terminal, battery (−) to L298N GND, and run a wire from L298N GND to Arduino GND for common ground. Carefully double-check polarity!

  8. Upload the Arduino Program

    Connect the Arduino to your computer via USB, open autoracerl298n.ino in the Arduino IDE, select Arduino UNO board and COM port, and click Upload.

  9. Test the Robot

    Place the robot on a clear floor, switch on the 7.4V battery, and observe it cruising forward smoothly at PWM 130 and steering away from obstacles when detected!

Safety Notes

⚠️Check battery polarity before connecting it to the circuit. Reversed polarity can permanently damage components.
⚠️Do not short-circuit the battery terminals. Never let bare wires touch both terminals at the same time.
⚠️Do not connect the 7.4V battery directly to Arduino signal or I/O pins. Use the motor driver module's regulated 5V supply path.
⚠️Keep fingers, loose wires, and clothing away from rotating wheels and motors while the robot is powered on.
⚠️Test the robot on a clear, flat surface away from ledges, stairs, and obstacles that could cause it to fall.
